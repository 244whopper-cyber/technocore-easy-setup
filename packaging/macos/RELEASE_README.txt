Technocore Easy Setup — macOS preview / macOS試用版

This app bundle includes Python and Tk. Python does not need to be installed separately.
This preview is ad-hoc signed but is not Apple Developer ID signed or notarized.
macOS may therefore refuse to open it. Do not disable macOS security globally.
Until a notarized release is available, running from source is the recommended option.

If macOS shows “TechnocoreEasySetup Not Opened”:
1. Verify that this ZIP came from the official GitHub Releases page and that its SHA-256
   matches the accompanying .sha256 file.
2. Click Done in the warning.
3. Open System Settings > Privacy & Security.
4. Scroll to Security and click Open Anyway for TechnocoreEasySetup.
5. Authenticate with your Mac login and click Open in the final prompt.
This allows this app only. Never disable Gatekeeper or macOS security globally.

このアプリにはPythonとTkが含まれるため、別途インストールする必要はありません。
この試用版はad-hoc署名されていますが、Apple Developer ID署名・公証は未実施です。
そのためmacOSが起動を拒否する場合があります。macOSのセキュリティ機能を全体的に
無効化しないでください。公証済み版が用意されるまではソースからの起動を推奨します。

「TechnocoreEasySetup Not Opened」と表示された場合:
1. ZIPが公式GitHub Releasesページからのもので、SHA-256が同時に配布される
   .sha256ファイルと一致することを確認します。
2. 警告画面でDoneを押します。
3. システム設定 > プライバシーとセキュリティを開きます。
4. セキュリティ欄までスクロールし、TechnocoreEasySetupの「このまま開く
   (Open Anyway)」を押します。
5. Macのログイン情報で認証し、最後の確認画面で「開く」を押します。
この操作はこのアプリだけを例外にします。GatekeeperやmacOS全体のセキュリティ機能を
無効化してはいけません。
